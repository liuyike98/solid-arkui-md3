## Switch 组件 MD3 样式实现（libs/components/Switch.tsx）

- 基于 @ark-ui/solid（zag.js）封装， zag 向所有 part 输出 `data-state="checked"/"unchecked"`、`data-hover`、`data-active`、`data-focus-visible`、`data-disabled`，样式全部用这些 data 属性驱动。
- MD3 规格要点：轨道 52×32 全圆角；未选中 = surface-container-highest + 2px outline 描边 + 16px outline 色滑块；选中 = primary 轨道 + 24px on-primary 滑块；按下滑块 28px；焦点 40px 指示环（opacity 0.2）；禁用整体 0.38。
- 项目 CSS 变量约定：`--s-*` 前缀 + 基线色回退（沿用 Ripple.tsx 风格），如 `--s-color-primary`、`--s-motion-duration-short4`、`--s-motion-easing-emphasized`。themes 目录尚为空，token 体系未建。
- 组件 API：`SwitchProps = SwitchRootProps`（透传给 ArkSwitch.Root），children 作为 Label 文案，无 children 时不渲染 Label。文件内不要加 `const StyleSheet = css``;` 占位（noUnusedLocals 会报 TS6133）。
- 注意：src/App.tsx 有预存的 TS6133（未使用的 createSignal 导入）。
- 修复：Switch 根元素在 flex column 父容器下被 align-items: stretch 拉伸占满整行，根元素加 `width: fit-content` 解决。
